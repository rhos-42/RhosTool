Après installation

  1. Extrayez le ZIP et lancez RhosTool.exe.
  2. Configurez Supabase via installer\link-supabase.ps1 ou %AppData%\RhosTool\config.json (mêmes valeurs que web/assets/config.js).
  3. Connectez-vous avec le compte créé sur cette page Compte.
